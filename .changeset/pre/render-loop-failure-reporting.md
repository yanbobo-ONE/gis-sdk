修复渲染循环停止时业务侧无感知：引擎在渲染循环里抛出致命错误后会停掉渲染（Cesium 会在画布上弹自己的错误面板），但这类失败不会让任何一次 SDK 调用失败、也不改变 `map.state` 与图层状态，业务只看到"画面不动了"，很容易当成卡顿去查。现在适配器监听引擎的渲染错误事件，转成一次 `map:error`，错误码为 `RENDER_LOOP_FAILED`（`module: 'scene'`，`cause` 为引擎原始错误，`retryable: false`——渲染循环不会自己恢复，需要重建地图），并且只上报一次，避免刷屏。验收台同时补了两处：面板单独显示 SDK 上报的致命错误（与操作结果分开，不被后续操作覆盖）；探针等待渲染帧时加了超时（标签页切到后台时浏览器会暂停 `requestAnimationFrame`，原先探针会永远停在"进行中"且清理逻辑跑不到，现在会明确失败并正常收尾）。
